# سیستم مدیریت فروشگاه

## 📋 نحوه اجرا در ویندوز 7
1. فایل `supermarket.exe` را اجرا کنید
2. اگر خطای DLL داد، ابتدا `fix_windows7.bat` را اجرا کنید
3. برنامه در مرورگر باز می‌شود: http://127.0.0.1:5000

## 👤 اطلاعات ورود
- **نام کاربری:** admin
- **رمز عبور:** admin123

## ❓ رفع مشکلات رایج

### مشکل ۱: خطای VCRUNTIME140.dll
✅ راه حل: فایل `fix_windows7.bat` را اجرا کنید

### مشکل ۲: خطای api-ms-win-core-path
✅ راه حل: این به‌روزرسانی را نصب کنید
https://www.microsoft.com/en-us/download/details.aspx?id=48234

### مشکل ۳: برنامه اجرا نمی‌شود
✅ راه حل: فایل `run.bat` را اجرا کنید
